# Automated Data Scraper & Excel Report Generator

A Python-based backend automation tool built to eliminate manual data entry. This script autonomously fetches live web data, cleans and processes text formats, and generates structured CSV reports compatible with Microsoft Excel and Google Sheets.

## 🚀 Business Value
* **Saves Time:** Automates hours of manual copy-and-paste data gathering.
* **Clean Data:** Converts raw web text and messy currency symbols into structured numeric fields.
* **Ready for Analysis:** Delivers instant, filterable spreadsheets directly to business managers.

## 🛠️ Built With
* **Python 3** - Core logic
* **BeautifulSoup4** - Web parsing and HTML data extraction
* **Requests** - HTTP networking

## 📋 How To Run
1. Install dependencies:
`pip install requests beautifulsoup4`
2. Run the automation script:
`python scraper.py`
